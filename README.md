# My Calculator - آلة حاسبة أندرويد

تطبيق آلة حاسبة بسيط للأندرويد يدعم العمليات الأساسية:

- ➕ الجمع
- ➖ الطرح
- ✖ الضرب
- ➗ القسمة
- 🔢 الأرقام العشرية
- 🗑️ مسح الشاشة
- ⌫ حذف آخر رقم
- ❗ معالجة القسمة على صفر

## الميزات

- واجهة مستخدم حديثة وداكنة (Dark Theme)
- الدعم الكامل للأرقام العشرية
- معالجة الأخطاء (مثل القسمة على صفر)
- خفيف وسريع

## متطلبات التشغيل

- Android 5.0 (API 21) أو أعلى

## بناء المشروع

```bash
./gradlew assembleDebug
```

الملف الناتج سيكون في:
```
app/build/outputs/apk/debug/app-debug.apk
```

## تثبيت التطبيق

1. حمل ملف الـ APK
2. فعّل "تثبيت التطبيقات غير المعروفة" في إعدادات الأندرويد
3. ثبّت الملف
